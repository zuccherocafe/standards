# Design reads

This folder holds one living design read per area of this repository, each recording what was read there and the disagreements still open between its models, as the [design-read skill](../../skills/design-read/SKILL.md) describes.

- [`change-process.md`](change-process.md): briefs, design reads and their check, writing, reviewing, and landing a change, and the coherence rules behind them.
- [`evals.md`](evals.md): the evals' tasks built from review findings, the control and treatment conditions, Harbor's runs of pi and the verifier, trial identity, and token and cost accounting.
- [`rust-mutants.md`](rust-mutants.md): the mutation report's runner, its build settings, repository and target copies, processes and their cleanup, and dandegate's call.
