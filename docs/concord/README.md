# Concord notes

This folder holds one living concord note per area of this repository, each recording what was read there and the disagreements still open between its models, as the [concord skill](../../skills/concord/SKILL.md) describes.

- [`change-process.md`](change-process.md): briefs, concord notes and their check, writing, reviewing, and landing a change, and the coherence rules behind them.
- [`rust-mutants.md`](rust-mutants.md): the mutation report's runner, its build settings, repository and target copies, processes and their cleanup, and dandegate's call.
