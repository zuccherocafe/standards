# Standards

This repository follows the zucchero✿café standards, which this container holds at `~/.agents/`. Before changing code, read `~/.agents/rules/general.md` and the standard for the changed language, the Rust standard in `~/.agents/rules/languages/rust/`. Review against `~/.agents/rules/review.md`.

Where the repository's own `AGENTS.md` and the standards disagree, the repository's file wins.

## Skills

The standards' skills in `~/.agents/skills/` define each role's work. Read the file for your role before starting:

- To write a change: `~/.agents/skills/change-write/SKILL.md`.
- To review a change: `~/.agents/skills/change-review/SKILL.md`.
- To write or edit prose, a commit message, or a report: `~/.agents/skills/technical-writing/SKILL.md` and `~/.agents/skills/unslop/SKILL.md`.
